⚙️ Analytical Methodology

This project strictly follows an evidence-based framework:

  1. DATA: Acquired and reconstructed 8-column dataset from UCI API.
  2. EVIDENCE: Isolated extreme outliers (80,995 units) and separated £362K operational items.
  3. INTERPRETATION: Applied RFM segmentation and Pareto analysis with strict interpretation boundaries (e.g., "bulk-purchasing indicators" instead of unproven "B2B" claims).
  4. ACTION: Delivered 6 prioritized management recommendations based on observed patterns.
